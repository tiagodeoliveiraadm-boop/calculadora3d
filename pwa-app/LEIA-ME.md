# Calculadora 3D - Casa Oliver
## Como publicar no Vercel e instalar no iPhone

### PASSO 1 — Criar conta gratuita no Vercel
1. Acesse https://vercel.com
2. Clique em Sign Up → Continue with Google

### PASSO 2 — Publicar o app
1. No painel, clique em Add New → Project
2. Arraste a pasta `pwa-app` para a área de upload
3. Clique em Deploy — aguarde ~2 minutos
4. Seu link estará pronto: ex: calculadora-casa-oliver.vercel.app

### PASSO 3 — Instalar no iPhone
1. Abra o link no Safari (não Chrome)
2. Toque no ícone de compartilhar (quadrado com seta)
3. Toque em "Adicionar à Tela de Início"
4. Pronto — ícone Casa Oliver na tela inicial!

### PASSO 4 — Compartilhar com o público
Basta enviar o link do Vercel para qualquer pessoa.
Para domínio próprio (ex: calculadora.casaoliver.com.br),
registre em registro.br (~R$40/ano) e aponte para o Vercel.
